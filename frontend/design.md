# Quran Online — Design Specification

## 1. Design Goal

The attached reference screenshot is the primary visual source of truth for the Quran Online website.

The website must be recreated as a highly faithful visual copy of the reference design.

Do not redesign the interface.

Do not introduce a different visual style.

Do not make it look like a generic SaaS website.

The final result should closely reproduce:

- Overall composition
- Section order
- Alignment
- Spacing
- Whitespace
- Colors
- Typography
- Card styling
- Borders
- Shadows
- Corner radius
- Background patterns
- Image treatment
- Buttons
- Navigation
- Footer
- Visual hierarchy
- Overall density and proportions

If a detail is not completely clear from the screenshot, choose the option that is visually closest to the screenshot and consistent with the rest of the design.

---

# 2. Overall Visual Style

The design is a premium, modern, minimalist Quran-learning website.

The visual feeling should be:

- Elegant
- Peaceful
- Professional
- Trustworthy
- Educational
- Refined
- Minimal
- Warm
- Spacious
- Contemporary
- Islamic in a subtle way

Avoid:

- Bright colors
- Neon colors
- Excessive gradients
- Excessive animations
- Heavy Islamic ornaments
- Crowded layouts
- Large decorative illustrations
- Generic SaaS styling
- Excessive rounded elements
- Excessive shadows
- Childish design
- Overly complicated UI

Whitespace is an important part of the design.

Do not fill empty areas unnecessarily.

---

# 3. Reference Screenshot

The supplied screenshot must be treated as the visual specification.

When implementing the website, continuously compare the implementation against the screenshot.

Pay particular attention to:

- Relative positioning
- Alignment
- Content width
- Section width
- Vertical spacing
- Horizontal spacing
- Typography hierarchy
- Image proportions
- Card proportions
- Button placement
- Pattern placement
- Background transitions
- Footer proportions
- Overall visual balance

The goal is visual fidelity, not creative reinterpretation.

---

# 4. Color Palette

The website uses a restrained palette consisting primarily of:

- Deep dark navy/blue
- Muted teal
- Pale aqua
- Warm white
- Soft gray
- Dark blue-gray text

The colors should visually match the screenshot.

Do not substitute them with random Tailwind default colors.

## Deep Navy / Blue

Used for:

- Primary buttons
- Dark sections
- Footer
- Important icons
- Primary UI elements
- Strong visual emphasis

The dark color should feel rich and calm.

Do not use pure black.

## Muted Teal

Used for:

- Accent words
- Section labels
- Small highlights
- Decorative details
- Icon accents
- Important secondary emphasis

The teal should be subtle and sophisticated.

Do not use neon or highly saturated teal.

## Pale Aqua

Used for:

- CTA background
- Soft highlighted areas
- Subtle feature backgrounds
- Decorative surfaces

It should remain very light.

## Page Background

The main page uses a warm/off-white appearance rather than an aggressive pure white.

White cards and surfaces should remain distinguishable from the surrounding background.

## Text Colors

Primary text should be dark blue-gray.

Secondary text should be muted gray-blue.

Avoid pure black body text.

---

# 5. Background Pattern

A subtle repeating geometric diamond/check pattern is one of the defining visual details of the design.

The pattern appears in:

- Hero section
- Personalized learning path section
- Final CTA section

The pattern must be:

- Very subtle
- Small
- Low contrast
- Repeating
- Geometric
- Elegant
- Light
- Consistent

It should look like a refined Islamic/geometric background texture.

The pattern must never compete with the content.

Do not replace it with:

- Random dots
- Large geometric shapes
- Loud Islamic ornaments
- Heavy patterns
- Colorful backgrounds
- Large gradients

Create the pattern as a reusable design treatment.

---

# 6. Typography

Typography is a major part of the visual identity.

Use two primary font styles.

## Display / Heading Font

Headings use an elegant editorial serif typeface.

The serif should feel:

- Refined
- Premium
- Literary
- Traditional
- Editorial
- Calm

The heading typography must closely resemble the reference.

Important heading words can use the muted teal accent.

Examples include:

"Making Quran Learning Easy for Everyone"

"Learning That Fits Your Life"

"Start Learning in 3 Steps"

"What Our Students Say"

"Frequently Asked Questions"

"Ready to Start Your Quran Journey?"

## Body Font

Body text uses a clean modern sans-serif.

It should feel:

- Simple
- Clean
- Professional
- Readable
- Lightweight
- Modern

Use the sans-serif consistently for:

- Navigation
- Paragraphs
- Card descriptions
- Buttons
- Labels
- Metadata
- FAQ items
- Footer content

## Typography Rules

Do not introduce random fonts.

Do not use decorative Islamic fonts.

Do not use multiple unrelated typefaces.

Keep the serif display font and clean sans-serif body font consistent throughout the website.

Do not hard-code text sizes inside this design specification.

Determine the visual typography scale from the reference screenshot while maintaining the same relative hierarchy.

---

# 7. Layout

The website uses a centered, controlled content container.

The content should not stretch unnecessarily across the entire screen.

The overall layout should feel editorial and carefully composed.

Use:

- Consistent container alignment
- Controlled content width
- Generous whitespace
- Consistent section spacing
- Strong vertical rhythm
- Clear visual hierarchy

All major sections should feel like they belong to the same design system.

Do not randomly change container widths between sections.

---

# 8. Navigation

The navigation is minimal and lightweight.

It contains:

- Quran Online logo/brand
- Home
- Courses
- About
- Testimonials
- Contact
- Book Free Trial CTA

The navigation should remain understated.

The CTA should be visually stronger than the navigation links but still fit naturally into the design.

Use:

- Clean alignment
- Minimal visual noise
- Dark primary CTA
- Subtle typography
- Generous whitespace
- No heavy borders
- No oversized navigation elements

The navigation should visually resemble the screenshot rather than a generic website navbar.

# 21. Cards

All cards across the website should feel like part of one unified system.

Common characteristics:

- White or subtle tinted background
- Soft border
- Very subtle shadow
- Rounded corners
- Clean internal spacing
- Minimal icon treatment
- Consistent visual hierarchy

Do not use heavy shadows.

Do not use extremely rounded pill-shaped cards.

Do not make every card look identical if its purpose differs, but maintain the same underlying design language.

---

# 22. Icons

Icons should be simple and minimal.

Use a consistent icon family throughout the website.

Icons should generally appear in:

- Small rounded/circular containers
- Muted teal
- Deep navy
- Pale aqua backgrounds

Do not mix many unrelated icon styles.

Avoid oversized icons.

Images are an important part of the design.

Use photography that communicates:

- Children/students

- One-on-one teaching
- Comfortable home environments
- Warm natural lighting

Images should feel authentic and premium.

All major images should have rounded corners consistent with the screenshot.

- Bright artificial stock-photo appearance
- Images with conflicting colors
- Excessively saturated images

The image crop and position should visually match the screenshot.

---

# 24. Responsive Design

The desktop screenshot is the primary reference.

The website must also be fully responsive.

On smaller screens:

- Navigation should transform into a mobile-friendly navigation.
- Hero columns should stack naturally.
- Course cards should become a suitable responsive grid.
- Feature cards should stack or wrap cleanly.
- Two-column sections should become one column.
- Learning path stages should remain readable.
- Three-step cards should stack appropriately.
- Platform cards should stack appropriately.
- Testimonials should stack appropriately.
- FAQ should remain easy to read.
- CTA content should remain centered and balanced.
- Footer columns should stack naturally.

Do not simply shrink the desktop design.

Preserve the design hierarchy and whitespace on mobile.

---

# 25. Animation Philosophy

Animations should be subtle.

The reference design is not animation-heavy.

Use only tasteful interactions such as:

- Small hover transitions
- Subtle card elevation
- Button hover transitions
- Gentle accordion transitions
- Small image transitions where appropriate

Avoid:

- Large entrance animations
- Excessive parallax
- Constant movement
- Bouncing elements
- Flashy effects
- Long animations

Animation must never distract from the content.

---

# 26. Accessibility

The design must remain accessible while matching the screenshot.

Ensure:

- Sufficient text contrast
- Keyboard-accessible buttons
- Keyboard-accessible navigation
- Accessible accordion controls
- Meaningful image alt text
- Proper semantic HTML
- Visible focus states
- Logical heading hierarchy

Accessibility should be implemented without changing the visual identity.

---

# 27. Component Design Philosophy

The frontend should be built from reusable components.

Examples:

- Navbar
- Footer
- Button
- SectionHeading
- FeatureCard
- CourseCard
- BenefitItem
- LearningPath
- StepCard
- PlatformCard
- TestimonialCard
- FAQAccordion
- CTASection

Do not duplicate large blocks of markup unnecessarily.

However, do not over-abstract simple elements into dozens of tiny components.

Components should have clear responsibilities.

---

- Borders
- Shadows

- Spacing
- Container alignment
- Background patterns

# 30. Final Visual Requirement

The finished website should look as though the screenshot was used as the original design reference during development.

The objective is not:

"Create a website similar to this."

The objective is:

"Recreate this exact visual design as faithfully as possible in Next.js."

Before considering any section complete, compare it against the reference screenshot and correct:

- spacing
- alignment
- proportions
- colors
- typography
- card appearance
- image treatment
- background pattern
- section height
- visual hierarchy

Do not stop at a rough approximation.

Prioritize visual fidelity and professional polish.
